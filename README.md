# Amazon-Sales-Inventory-Analysis

## Project Overview
This project analyzes Amazon sales and inventory data using Python, MySQL, and Power BI.

## Tools Used
- Python
- MySQL
- Power BI

## Key Metrics
- Total Revenue: ₹78.59M
- Total Orders: 129K
- Total Units Sold: 117K

## Dashboards
### Executive Dashboard
- Revenue Analysis
- Order Analysis
- State-wise Revenue

### Sales Dashboard
- Top Categories by Revenue
- Top SKUs by Revenue
- Revenue by Fulfillment

### Inventory Dashboard
- Stock Distribution
- Inventory by Category
- Inventory by Size
- Stock Status Analysis

## Skills Demonstrated
- Data Cleaning
- SQL Querying
- Data Analysis
- Data Visualization
- Dashboard Development
